# 🛠 React + TypeScript + Vite  

¡Hola y bienvenido! 👋  

Este proyecto fue una de mis primeras pruebas técnicas, desarrollada en **42 minutos** ⏳. Fue una gran oportunidad para fortalecer conocimientos y evaluar la rapidez en la implementación de tecnologías modernas.  

## 🚀 Tecnologías utilizadas  

- **React** ⚛️ - Librería para construir interfaces de usuario interactivas.  
- **TypeScript** 📝 - Superset de JavaScript con tipado estático.  
- **Vite** ⚡ - Entorno de desarrollo rápido y optimizado.  
- **ESLint** 🔍 - Herramienta para mantener un código limpio y libre de errores.  

## 🔧 Configuración de ESLint  

Si estás desarrollando una aplicación para producción, es recomendable actualizar la configuración para habilitar reglas de lint con reconocimiento de tipos.
